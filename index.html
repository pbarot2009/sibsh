A shell built from scratch
in Rust, std-only.

sibsh (Something Is Better Shell) is a lightweight, zero-dependency Unix shell. No crates, no frameworks — just the Rust standard library and a determination to build something fast and reliable by hand.

Built entirely using the Rust standard library. No crates, no cargo dependencies to audit, no supply chain to worry about.

Starship-style two-line prompt: git branch and dirty flags, SSH-only user@host, language detection, 2-second execution timer, exit badge, and root mode.

Command parser

Supports single quotes, double quotes, escape characters, and environment variable expansion ($VAR, $?) with quote-aware operator detection.

$VAR$?
F.05 / I/O

I/O redirection

Create/truncate (>), append (>>), and stdin (<) for external commands and built-ins. Quote-aware so echo 'a > b' stays literal.

>>><
F.06 / Completion
⇥

Tab completion

First Tab completes built-ins, aliases, $PATH executables, and file paths. A second Tab lists all candidates. Full line editing and history navigation.

Tab×2arrows

⚙

Define with alias name='value', remove with unalias. Loaded from config at startup. First-word expansion happens once (no recursion).

§ 02 — The Prompt

A prompt that tells you everything.

Two-line segment prompt in the starship / oh-my-posh style. Every segment is a piece of information — and it renders differently across all seven operational states below.

[sibsh] — Brand segment
Fixed brand identifier in ANSI-256 violet. Always present.
~/code/sibsh — Directory
Current working directory. $HOME shows as ~. Paths deeper than 3 levels contract leading segments to …/.
⎇ main — Git branch
Current branch from one git status --porcelain -b call per prompt. Hidden outside repositories. Disable with git_status = false.
[⇡2 ⇣1 !3 ?1] — Dirty flags
⇡N ahead / ⇣N behind upstream, !N modified or staged files, ?N untracked files.
rs v1.23 — Runtime detection
Project language by files present: Cargo.toml → rs, go.mod/*.go → go, CMakeLists.txt/C & C++ sources → c.
[3.42s ⏱] — Execution timer
Shows only when the previous command took longer than 2 seconds (2000ms).
[127 ✘] — Exit code badge
Renders only on non-zero exit codes. The input pointer turns from green ❯ to red ❭.
❯ — Input pointer
Green on success ($? == 0), red on failure. In root mode (UID 0) it becomes a bold gold # and runtime segments are dropped.

§ 04 — Getting Started

Build it in three commands.

Requires Rust 1.80+ and Cargo. That's it.

install.sh bash 
# Clone and build from source
git clone https://github.com/pbarot2009/sibsh.git
cd sibsh
cargo build --release

# Binary lands at ./target/release/sibsh

# Run with cargo:
cargo run

# Or run the compiled binary:
./target/release/sibsh
example-session.sh bash 
# Inspect environment and working directory
pwd
echo "Running as user: $USER"

# Directory navigation
cd /tmp
pwd
cd -

# Manage variables
export PROJECT="sibsh"
echo $PROJECT

# I/O redirection
echo "Hello, World" > greeting.txt
cat greeting.txt
echo "Second line" >> greeting.txt

# Quoted operators stay literal
echo 'a > b'    # prints: a > b

# Aliases
alias ll='ls -la'
ll
unalias ll

# Exit codes
false
echo $?      # prints: 1
§ 05 — Configuration

One file, plain TOML.

~/.sibsh/sibsh.toml — or override with $SIBSH_CONFIG. Missing or invalid config never blocks startup.

~/.sibsh/sibsh.toml toml 
# Custom single-line prompt template
# Placeholders: {user} {host} {cwd} {status} {branch}
# prompt = "{user}@{host}:{cwd} ❯"

icons = "ascii"          # plain glyphs instead of Nerd Font
git_status = true          # false hides git segment
history_limit = 1000      # cap on in-memory history
imports = ["~/.bashrc", "~/.zshrc"]

[aliases]
ll = "ls -la"
gs = "git status"
config-behavior.txt text 
# How imports work
Imported files run bashrc/zshrc style:
  - export KEY=VAL     → sets environment variable
  - alias name='val'   → defines alias
  - # comments          → skipped
  - plain commands      → executed
  - bash-only syntax    → skipped silently

# First run
On first run, sibsh writes a fully commented
template to ~/.sibsh/sibsh.toml explaining every
option. The same file ships in the repo as
sibsh.toml.example.

# Error handling
A missing or invalid config never prevents
startup. Parse errors report the line number.

# Override path
export SIBSH_CONFIG=/custom/path.toml

§ 07 — Changelog

Every version, documented.

Keep a Changelog format. Semantic versioning.

0.1.45 2026-08-23 LATEST
Added
  • Two-line, segment-based prompt in the starship / oh-my-posh style with git status, language detection, execution timer, exit badge, SSH detection, root mode, path truncation, ANSI-256 palette, and ASCII icon mode.
  • Git segment: branch + dirty-state flags (!N modified, ?N untracked, ⇡N ahead, ⇣N behind) from one git status --porcelain -b call per prompt.
  • {branch} placeholder for custom prompt templates.
Changed
  • Line editor repaints multi-line prompts correctly — redraws move up over every prompt line and completion list, clear to end of screen, then rewrite.
  • Test suite grew to 131 tests (84 unit + 47 integration), pinning environment identity so tests pass as root or non-root, local or CI.
0.1.4 2026-08-23
Fixed
  • Interactive mode showed two prompts on one line. Prompt rendering now belongs entirely to the line reader (completion::read_line), matching zsh's ZLE / fish model.
  • Non-terminal input (piped scripts) keeps its prompt output; fallback path prints once before reading.
  • CI failure completes_builtin_commands: completion unit tests depended on real $PATH. New complete_in() takes an explicit directory list; tests use synthetic directories.
  • cargo fmt --all applied to all sources.
0.1.3 2026-08-23
Added
  • Tab completion (std-only via stty raw mode): first word completes builtins, aliases, $PATH executables; other words complete paths. Line editing, history navigation, Ctrl+C clears line, Ctrl+D exits.
  • Configuration file ~/.sibsh/sibsh.toml: prompt template, history_limit, [aliases] table, imports. Parsed by std-only TOML subset parser.
  • Aliases: alias builtin (list all or define) and unalias. First-word expansion, no recursion.
Changed
  • touch now updates modification time of existing files via File::set_modified.
  • Prompt rendering supports config templates (Prompt::render_with).
  • Test coverage grew to 100 tests: 60 unit + 40 integration.
0.1.2 2026-08-22
Added
  • I/O Redirection for external commands and built-ins: > truncate, >> append, < stdin.
  • Multiple redirections per line; last target per stream wins.
  • Quote-aware operator parsing: echo 'a > b' stays literal. Attached and spaced forms both work.
  • $VAR / $? expansion inside filenames. Quoted filenames may contain spaces.
  • New syntax errors: missing filename after operator, empty filename from expansion.
  • ShellError::Redirection variant with clear messages.
Changed
  • All printing built-ins write through an explicit output handle instead of global stdout.
  • cat is now byte-safe (io::copy).
  • REPL reads stdin per-call instead of holding the lock across dispatch.
0.1.1 2026-08-21
Added
  • Project documentation: CHECKLISTS.md with phase-by-phase roadmaps, design decisions, edge-case matrices, and definitions of done.
0.1.0 2026-08-21 INITIAL
Added
  • Core interactive REPL loop with colored prompt.
  • Tokenizer: single quotes, double quotes, escapes, $VAR / $? expansion.
  • PATH lookup and external process execution.
  • In-memory command history (history).
  • 16 initial built-in commands: cd, pwd, echo, exit, help, clear, type, which, env, export, unset, history, touch, cat, true, false.
  • Graceful exit on EOF (Ctrl+D) and custom exit status propagation.
